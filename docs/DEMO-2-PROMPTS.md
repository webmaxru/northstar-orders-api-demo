# Demo 2 prompt sequence

## Read

Read WI-1842, `AGENTS.md`, architecture, and ADR-007. Summarize acceptance criteria and ambiguities. Do not edit files.

## Plan

Propose a transaction-safe implementation plan. Cite files, map tests to criteria, state the capability boundary, and stop before edits.

## Implement

Implement the approved plan. Run focused tests, then PostgreSQL acceptance tests. Stop on schema, dependency, public API, workflow, or permission changes that were not approved.

## Review

Produce the evidence bundle and recommend merge, revise, revert, or escalate.
