# WI-1842: Stop duplicate orders after client retries

> **Synthetic demo work item.** Northstar Commerce and all identifiers in this repository are fictional.

Clients retry `POST /orders` when a network timeout hides the first response. The API can currently create a second order.

## Acceptance criteria

1. The same `Idempotency-Key` and payload within 24 hours returns the original order.
2. The same key with a different payload returns HTTP `409`.
3. Concurrent retries create exactly one order.
4. Requests without a key preserve the current behavior.
5. Raw keys and request payloads are not logged.
6. Replays and conflicts emit metrics.
